# My AI Usage

## Tools used
- ChatGPT (OpenAI): used as a coding and learning assistant to turn the kata requirements into a project scaffold, explain the architecture, draft tests and documentation, and suggest implementation approaches.

## How AI was used
- Organized the requirements into backend, database, authentication, frontend, testing, and documentation tasks.
- Drafted a FastAPI API structure, SQLAlchemy models, JWT helper functions, and React UI components.
- Drafted initial pytest cases for registration, login, authorization, vehicle creation, and stock decrement.
- Drafted local setup instructions and a checklist of security and testing limitations.

## Human review and verification
The developer must run the application and tests locally, inspect the code, understand each route and test, fix any environment-specific issues, and add tests for uncovered cases.
